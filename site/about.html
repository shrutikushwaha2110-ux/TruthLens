How TruthLens uses Claude Code

Five Claude Code building blocks work together on this project — here's what each one does, in one line.

Skill — verdict-rules

The exact rules for turning raw detector scores into an honest verdict and confidence, so Claude follows the same logic every time it analyzes content.

Subagent — feed-auditor

Scrolls a real YouTube Shorts feed with a Claude-controlled browser, scores each Short, and writes an audit report — see Audit.

Hook — quality_check

Runs after every file write or edit and blocks accidental API keys and broken website HTML (missing lang, title, nav, footer, or image alt text) before they land.

MCP — truthlens

Gives Claude two tools, analyze_image_file and analyze_image_url, that call the same detector backend the browser extension uses.

MCP — Playwright

Gives Claude a real, controllable browser, so the feed-auditor subagent can actually scroll and screenshot a live feed instead of guessing what's on it.

Plugin — truthlens

Packages the Skill, Subagent, Hook, and both MCP servers together so they can be installed into any other Claude Code project in one command.
