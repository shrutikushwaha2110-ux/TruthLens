Why 2 models and 3 frames?

One detector can be confidently wrong. Running two independently-trained open-source models (Ateeqq/ai-vs-human-image-detector and Organika/sdxl-detector) and checking whether they agree is a cheap, honest way to catch that — when they sharply disagree, TruthLens says "Unsure" instead of picking one at random. Sampling 3 frames across a Short (not just the thumbnail, and not every single frame) balances catching a clip that changes partway through against the cost of running two CPU models per frame.

In practice we also found the two models aren't equally reliable on ordinary, re-compressed social video: one of them reads noisy and biased high on real footage more often than the other. Rather than hide that, TruthLens takes the median of each model's score across the 3 frames (so one noisy frame doesn't swing the result) and weights the more reliable model more heavily in the final blend — an adjustment made from real testing data, not a guess.

How MCP connects Claude

Two MCP (Model Context Protocol) servers let Claude Code act on this project directly. The custom truthlens MCP server exposes the same detector the browser extension uses, so Claude can analyze any local image or URL on request. The Playwright MCP server gives Claude a real, controllable browser. The feed-auditor subagent combines both: it scrolls a live YouTube Shorts feed with Playwright, screenshots each Short, scores it with the truthlens MCP tools, and writes a report — see Audit for the results of real runs.

Honest limits

Samples frames, not every frame

3 frames per Short is enough to catch most content, but a clip that's real for 2.9 seconds and switches at the very end could be missed.

No audio deepfake check yet

TruthLens only looks at video frames right now — a real video with a cloned voice dubbed over it isn't something this version can catch.

Laptop Chrome only

The extension runs in desktop Chrome. It doesn't run inside the native YouTube, Instagram, or Facebook phone apps.

No detector is perfect

Free, open-source detectors lose real accuracy on in-the-wild content — that's the whole premise behind this project (see Research). Confidence is capped at 95% and "Unsure" is a valid, honest answer, not a failure.
