Install

Run TruthLens locally

Everything runs on your own machine — no account, no paid API, no data leaving your computer except the fact-check lookup (optional, off by default).

1. Start the backend

From the project root, in a terminal (Windows):

backend\.venv\Scripts\python.exe -m uvicorn app:app --port 8000 --app-dir backend

The first run downloads both detector models from Hugging Face, which can take a few minutes. Leave this terminal running — the extension, this website, and the audit subagent all depend on it being up at http://localhost:8000.

2. Load the Chrome extension

  1. Open chrome://extensions
  2. Turn on Developer mode (top-right toggle)
  3. Click Load unpacked
  4. Select the extension folder inside the project (not its parent folder)
  5. Open youtube.com/shorts and scroll — a badge should appear on the active Short within a few seconds

If you edit extension files, click the reload icon on the TruthLens card in chrome://extensions to pick up the changes.

3. Optional: Claude Code integration

The truthlens and playwright MCP servers are registered in .mcp.json at the project root and are offered for approval when Claude Code starts in this folder. Check /mcp to confirm both are connected, /agents for the feed-auditor subagent, and /hooks for the quality-check hook. See About for what each piece does.
